Add an item called Item Resume. Right clik when holding the item can consume it to get a random item, that random item can be vanilla item, other mods' item, or items that can not be obtained like fire and command block, as long as it exists within the game's registry.

The Item can not be crafted, but you can add recipe using craft tweaker mod.

About the 任务.zip, it adds quests for the modpack GTNH. It adds a chapter called 抽卡. In the chapter, there are two quests: 单抽 and 十连抽. For 单抽, submit 600 Orundums to get an Item Resume. For 十连抽, submit 6000 Orundums to get 10 Item Resume.

Extract the 任务.zip into config\betterquesting\DefaultQuests. And open config\betterquesting\DefaultQuests\QuestLinesOrder.txt, add the follwing line: uWrou5I3TY6h48ZpJL22VA==: 抽卡

添加了一个叫物品简历的物品，手持该物品右键可以将其消耗并获得一个随机物品，那个随机物品可以是原版物品、其他mod的物品，或无法获取的物品，例如火焰和命令方块，只要它存在于游戏注册表中就都可以获取。

这个物品无法合成，但你可以使用craft tweaker为其添加合成表
